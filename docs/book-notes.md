# Идеи из книги «Структурные методы распознавания образов»

Конспект подготовлен для проекта `book-meta`. 
В книге описаны классические подходы структурного распознавания. Ниже - выжимка идей, которые мы можем применить для поиска формул, рисунков и таблиц.

## 1. Поиск таблиц (структурный подход)
- **Идея из книги:** Разбиение изображения на примитивы (линии, пересечения) и построение графа связей между ними.
- **Где применяем у нас:** В заготовке Богдана (поиск линий) и в `FigureExtractor`. Нам нужно искать горизонтальные и вертикальные линии, а на их пересечениях строить "ячейки" таблицы.

## 2. Поиск формул и номеров (анализ контекста)
- **Идея из книги:** Использование априорной информации о расположении объекта (структурные признаки).
- **Где применяем у нас:** В `FormulaExtractor._find_number()`. Формулы в книгах почти всегда выровнены по правому краю, а номер обрамлен круглыми скобками `(1)`, `(2.3)`. Мы можем использовать это как "якорь" для поиска.

## 3. Поиск рисунков (векторный анализ)
- **Идея из книги:** Группировка множества мелких примитивов (векторов) в единый объект по пространственной близости.
- **Где применяем у нас:** В `FigureExtractor._cluster_vectors()`. Если мы извлекаем векторные линии из PDF, нам нужно объединить их в один рисунок, если они находятся рядом.

## 4. Отсев мусора (оценка качества)
- **Идея из книги:** Использование статистических признаков для классификации "сигнал/шум".
- **Где применяем у нас:** В задаче Ярослава (оценка качества скана). Контрастность и резкость можно оценивать через гистограммы и преобразование Фурье.
